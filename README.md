## 🎮 About
**Aqua Guess** is a fun and interactive number guessing game designed to make your web experience exciting and engaging. Users can choose between **Easy, Medium, and Hard levels**, with limited attempts for a challenge. The game provides instant feedback and celebrates your victories with interactive messages and animations.

---

## 💡 Features
- **3 Difficulty Levels:** Easy (1–10), Medium (1–50), Hard (1–100)  
- **Limited Attempts:** Users must guess within maximum tries  
- **Interactive UI:** Aqua-inspired colors, animated headings, glowing success messages, and shake effect on errors  
- **Responsive Design:** Works beautifully on mobile, tablet, and desktop  
- **Keyboard Support:** Press **Enter** to submit a guess

## ⚡ How to Play
1. Select your **difficulty level**.  
2. Guess the secret number within the **allowed attempts**.  
3. Feedback will guide you if the number is too high or too low.  
4. Win the game to see the **celebration message**.  
5. Press **Reset** to start again.
